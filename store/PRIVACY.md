# 隐私政策（Privacy Policy）

**鲸鱼邮箱 · DeepSeek 聊天小助手**

最后更新：2026 年 8 月

## 概述

本扩展尊重并保护用户隐私。本政策说明扩展如何收集、使用和存储数据。

## 我们收集什么

1. **本地存储数据**：聊天记录、角色人设、自定义角色、开关状态、图标位置，以及（可选）你填写的 DeepSeek API Key——**全部仅保存在你本机的浏览器 localStorage 中，不上传到任何服务器**。
2. **智能回复请求**：仅当你手动开启「智能回复」时，你的聊天消息与角色人设提示词会发送到 DeepSeek 官方 API（api.deepseek.com）用于生成回复。这属于功能必需的数据传输。

## 我们不收集什么

- 不收集个人身份信息（姓名、邮箱、账号密码、地理位置等）
- 不含任何分析统计、广告 SDK、埋点或行为追踪
- 开发者无法访问、也无法查看你的任何数据

## 数据存储与删除

- 所有数据仅存在于你的本地浏览器。清除浏览器数据、或在扩展管理页卸载扩展，即可删除全部数据。
- API Key 同样仅存本地，仅用于调用 DeepSeek API。

## 第三方服务

- **DeepSeek API**（api.deepseek.com）：仅在「智能回复」开启时接收你的消息以生成回复，请参阅 [DeepSeek 官方隐私政策](https://platform.deepseek.com)。
